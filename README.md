# L-PANEL

Multi Server OCServ VPN Management Panel

## Features

- Multi OCServ Server Management
- VPN User Management
- Multi Admin
- Reseller System
- Role Permission System
- Backup Management
- API Support


## Requirements

- PHP 8.3+
- Laravel 12
- PostgreSQL
- Nginx
- Redis
